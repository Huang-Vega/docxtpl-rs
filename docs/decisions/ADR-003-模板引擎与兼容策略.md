# ADR-003：模板引擎选型与 MiniJinja/Jinja2 兼容策略

- 状态：已接受（P0）
- 决策日期：2026-09-24

## 决策

1. 渲染引擎选用 **MiniJinja 2.x**：语法、过滤器、空白控制与 Jinja2 高度对齐，纯 Rust、无 Python 依赖。
2. 默认值对齐上游：
   - `autoescape = false`（上游 `render(context, jinja_env=None, autoescape=False)` 默认）；
   - undefined 采用 lenient 行为（渲染为空串，`{% if %}` 视为假），对齐 jinja2 默认 `Undefined`；
   - 空白控制 `trim_blocks=false / lstrip_blocks=false`，`{%- -%}` 语义同 jinja2。
3. 上游在渲染前向每个 `<w:p[ >]` 前插入 `\n`、渲染后移除，仅为行号定位与差分无关；同样实现。
4. 语法子集声明：支持变量、表达式、内置过滤器（upper/lower/join/length/default/replace/trim 等内建集合）、
   if/for/set/宏不承诺/注释 `{# #}`、空白控制、字面 `{_{ }_}` 转义。
   不支持：Jinja2 扩展、line statements、Python 对象/可调用、自定义 env 注入。
5. 每个启用的过滤器/测试记入 `docs/compatibility.md` 支持矩阵；不笼统宣称“完全兼容 Jinja2”。

## 验证

MiniJinja 与 Jinja2 的行为差异全部通过 oracle 差分暴露；fixture 至少覆盖
过滤器、默认值、undefined、空白控制、循环变量 `loop`。
