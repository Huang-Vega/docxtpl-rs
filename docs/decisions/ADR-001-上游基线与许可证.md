# ADR-001：固定上游基线与许可证义务

- 状态：已接受（P0）
- 决策日期：2026-09-24

## 背景

项目以“保留语义的移植”为目标，必须固定单一上游参考实现，否则等价判定无从谈起。

## 决策

1. 固定基线为 **docxtpl 0.20.2**：
   - PyPI sdist：`docxtpl==0.20.2`（2025-11-13 发布，即当前最新版）。
   - Git tag `v0.20.2`，commit SHA `cf5437bdf5d30f9362149ddea508d6d9f008b6cd`。
   - 上游源码以 `pip download --no-binary :all:` 方式取至 `third_party/`（该目录不入库，见 `.gitignore`）。
2. Python 侧依赖（jinja2、python-docx、lxml）在 `tests/oracle/requirements.txt` 精确锁定；oracle 报告记录完整版本指纹。
3. 上游声明许可证 **LGPL-2.1-only**。本移植在 patch 步骤中逐条转录了上游的正则表达式与算法结构，构成衍生作品的可能性较高，因此 workspace 统一声明 `LGPL-2.1-or-later`，不复制上游源码进仓库。
4. P8 发布 1.0.0 前需复核：确认衍生性边界（正则/算法 vs 文字代码）并重新评估许可证声明；fixture 模板全部为本项目生成，无第三方再分发问题。

## 后果

- 升级基线是独立里程碑，必须附带完整差分报告。
- 任何行为 PR 的上游证据引用必须指向该固定版本。
