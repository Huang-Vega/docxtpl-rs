# ADR-001: Pinned Upstream Baseline and License Obligations

- Status: Accepted (P0)
- Decision date: 2026-09-24

## Context

The project aims at a "semantics-preserving port". A single upstream reference implementation must be pinned; otherwise equivalence claims have no basis.

## Decision

1. The baseline is pinned to **docxtpl 0.20.2**:
   - PyPI sdist: `docxtpl==0.20.2` (released 2025-11-13, i.e. the latest version at the time).
   - Git tag `v0.20.2`, commit SHA `cf5437bdf5d30f9362149ddea508d6d9f008b6cd`.
   - The upstream source is fetched into `third_party/` via `pip download --no-binary :all:` (this directory is not checked in; see `.gitignore`).
2. Python-side dependencies (jinja2, python-docx, lxml) are pinned exactly in `tests/oracle/requirements.txt`; the oracle report records the full version fingerprints.
3. The upstream declared license is **LGPL-2.1-only**. Because this port transcribes the upstream regular expressions and algorithm structures item by item during the patch step, it is fairly likely to constitute a derivative work. The workspace therefore uniformly declares `LGPL-2.1-only`, and no upstream Python source file is copied verbatim into the repository.
4. The final 1.0 license review was completed on 2026-09-27. It conservatively treats the port as a derivative work and rejects the earlier `LGPL-2.1-or-later` declaration because it would offer a later-version choice that the pinned upstream baseline does not grant. The complete LGPL 2.1 text is included in the workspace and every crate package. Apart from the 16 docxtpl 0.20.2 LGPL-2.1-only test templates registered in ADR-009, fixtures are generated by this project; the manifest records the upstream version, repository, tag, commit, license, and per-template source path.
5. docxtpl-rs is an independent project and does not claim affiliation with or endorsement by the Python docxtpl project. Python docxtpl and its templates remain repository-only development and compatibility evidence; they are not runtime dependencies or contents of the published Rust crates.

## Consequences

- Upgrading the baseline is a standalone milestone and must be accompanied by a full diff report.
- Upstream evidence cited by any behavioral PR must point to this pinned version.
